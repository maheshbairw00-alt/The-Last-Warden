# The Last Warden

लोडिंग, लॉगिन और लॉबी स्क्रीन का वेब प्रोटोटाइप। `index.html` से चलता है।

- Guest से लॉबी खुलती है।
- Google और Facebook लॉगिन अभी जुड़े नहीं हैं।
- PLAY, Inventory, Friends, Shop और Settings अभी सिर्फ़ बटन हैं।
- `assets/music.wav` कोड से बनाया गया ओरिजिनल लूप है।
- `assets/*.svg` अस्थायी ड्रॉइंग हैं।
